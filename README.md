## 🔍 Research Focus

My research investigates privacy-preserving machine learning for network security, specifically:

- **Federated Learning** for collaborative threat detection without centralized data exposure
- **Differential Privacy** mechanisms to protect sensitive network patterns while enabling analytics
- **Byzantine-Robust Aggregation** to secure distributed systems against adversarial manipulation
- **MITRE ATT&CK Framework** integration for standardized threat modeling in AI-driven security
- **Trustworthy AI** in cybersecurity contexts, exploring explainability and reliability of ML-based defense systems
